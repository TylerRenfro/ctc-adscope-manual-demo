# AdScope

Marketing site for AdScope, which changes your ads automatically based on live weather, location, time, and activity.

## Open it

Drag `index.html` into a browser window, or double-click it. There's nothing to install and nothing to build. You do need an internet connection, because Tailwind and the font load from the web.

To make a change, open a file in any text editor, save it, and refresh the browser.

## What's here

| File | What it is |
|---|---|
| `index.html` | The home page |
| `demo.html` | The early access page and its form |
| `styles.css` | A few custom styles. Tailwind classes in the HTML do the rest. |
| `images/` | Photos used in the ad previews |

## Built with

- [Tailwind CSS](https://tailwindcss.com), loaded from a CDN
- [Inter](https://fonts.google.com/specimen/Inter), from Google Fonts
